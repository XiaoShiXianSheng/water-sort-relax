一、概述

《解压水消除》（Water Sort Relax，以下简称"本游戏"）是一款单文件 HTML5 休闲益智小游戏，玩法是将彩色液体分装到对应的试管中，过程轻松、解压。本游戏由本页顶部公示的开发者（以下简称"我们"）开发与运营。

我们非常重视您的隐私。这份政策用尽量平实的语言，向您说明：我们处理了哪些信息、为什么处理、如何处理，以及您对自己信息所拥有的权利。请您特别阅读"三、我们不收集什么"一节——如实说明我们的产品特点，也是本游戏相对同类产品的真实优势。

本游戏面向全年龄用户，内容仅涉及分装彩色液体的解压玩法，不含暴力、恐怖、赌博等元素。

二、我们如何收集和使用信息

处理的目的与方式

我们处理信息的唯一目的，是向您提供并持续改进游戏体验，以及在您主动选择时向您展示广告。处理方式分为两类：

  • 本地处理：游戏进度等数据仅保存在您自己的设备浏览器中（详见第四节），用于让您下次打开时继续游戏。
  • 由第三方广告 SDK 处理：当您选择观看广告时，与广告相关的信息由 TapTap 广告 SDK 在其运行环境中处理（详见第五节）。

我们自身处理的个人信息种类

我们自身不收集、不上传任何个人信息。本游戏没有账号系统，不会采集您的姓名、手机号、邮箱、身份证号、家庭住址等任何能够识别您身份的信息。游戏内的操作事件仅在您的设备本地记录（见第四节），不会发生任何网络上报。

与广告投放相关的设备标识等信息，由 TapTap 广告 SDK 按其自身隐私政策处理，我们不掌握、也不向其额外提供您的个人信息。

三、我们不收集什么

为了让您放心，我们明确说明本游戏不做以下事情：

  • 不收集身份信息：本游戏无账号、无登录、无用户 ID；不采集姓名、手机号、电子邮箱、身份证号、地址等任何个人身份信息。
  • 不申请任何系统权限：游戏不会申请或使用定位、麦克风、摄像头、相册、通讯录、剪贴板、设备文件访问等任何系统权限。
  • 不使用 Cookie：本游戏不使用 Cookie 或其他同类跟踪技术。
  • 不上传任何数据：游戏内埋点的上报地址为空，所有事件只在您的设备本地缓冲，不存在任何网络上报行为。
  • 唯一的联网行为来自广告：游戏本身可完全离线运行；只有在您主动选择观看广告时，才会因广告 SDK 产生联网。

四、本地存储说明

本游戏使用浏览器本地存储（localStorage）保存少量数据，全部只存在于您自己的设备上，不会上传到任何服务器。仅包含两个存储键：

  • wsr_save_v1：保存您的游戏进度，包括当前关卡、关卡星级、已解锁的档位、每日挑战记录。
  • wsr_ev：保存最近 80 条游戏内事件，仅用于本地调试核对，不涉及任何个人信息。

本地存储的数据只服务于您个人的游戏体验，我们既看不到，也不会读取或收集这些内容。

五、第三方共享（广告 SDK）

本游戏唯一的第三方交互是 TapTap 广告 SDK。广告由 TapTap 小游戏运行环境注入的全局对象提供，我们仅调用它来拉取以下两类广告：

  • 激励视频广告：需要您主动点击才会触发，观看完成后您可获得游戏内的相应奖励。
  • 插屏广告：为不打扰您，我们将其频率限制为单个游戏会话最多 1 次，并且两次之间设有 300 秒冷却时间。

广告 SDK 可能会为广告投放、频次控制、反作弊等目的而处理设备标识等信息，这部分行为由其按照自身的官方隐私政策处理，我们不予干预，也不向其提供额外的个人信息。

广告位通过 TapTap 旗下的 Dirichlet 媒体平台进行配置与下发。除广告 SDK 自身运行所需外，我们不会与任何第三方共享您的个人信息。

如您希望了解或管理广告 SDK 对设备信息的处理，请查阅 TapTap 官方隐私政策，或通过其平台提供的相关设置进行管理。

六、信息的保存期限

由于我们自身不收集、不上传任何个人信息，因此不存在服务器端的个人信息保存期限问题。您设备上的本地数据（见第四节）会一直保留，直到您主动清除浏览器数据或卸载游戏。

与广告相关的设备信息由 TapTap 广告 SDK 按其政策处理，保存期限请以其官方隐私政策为准。

七、您的权利

根据《中华人民共和国个人信息保护法》等相关规定，您对自己的信息享有以下权利。结合本游戏"不上传任何数据"的特点，说明如下：

  • 查阅、复制、更正：我们自身不在服务器端保存您的个人信息，因此无相关记录可供查阅或更正。您设备上的游戏数据，您可随时通过游戏内进度直接使用。
  • 删除：您对本地数据拥有完全控制权。清除浏览器数据或卸载游戏，即可彻底删除全部本地数据（包括进度与事件记录）。
  • 撤回同意：您可随时停止游玩并清除本地数据来撤回对本地数据存储的同意；对于广告 SDK 对设备信息的处理，您可通过 TapTap 平台的相关设置撤回或管理。
  • 投诉：如您认为我们的处理损害了您的合法权益，您可以向有关监管部门投诉，也可通过本页顶部公示的联系邮箱与我们沟通，我们会认真处理。

由于本游戏不采集身份信息、不上传任何数据，您无需向我们发起"注销账号"之类的请求——因为根本不存在需要注销的账号或服务器档案。

八、未成年人保护

本游戏面向全年龄，内容健康，且不收集任何身份信息，对未成年人同样适用上述"不收集"原则。

我们建议未成年人的监护人对未成年人使用电子设备的情况予以关注与引导。如监护人发现未成年人设备上存在本游戏的本地数据，通过清除浏览器数据或卸载游戏即可完全删除，无需其他操作。

九、政策更新

我们可能根据法律法规或产品变化适时更新本政策。当更新涉及实质性变化时，我们会通过本游戏内提示或在本页面公示的方式通知您。本政策版本为 v1.0，生效日期为 2026-09-29。

政策更新后，若您继续使用本游戏，即视为您理解并同意更新后的内容。

十、联系方式

如您对本隐私政策或我们的隐私实践有任何疑问、意见或请求，可通过本页顶部公示的开发者名称与联系邮箱与我们联系。

我们将在合理时间内对您的来信予以回复。
