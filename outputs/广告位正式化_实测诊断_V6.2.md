## 二、为什么「切正式」点不动：三道门，一道一道试出来的

### 门 1：推广位属性里的「正式」是禁用的

编辑 `1067564` 时，DOM 里是这样的：

```html
<input type="radio" value="SPACE_TYPE_FORMAL" disabled="disabled">   <!-- 正式，禁用 -->
<input type="radio" value="SPACE_TYPE_TEST"   checked>                <!-- 测试，选中 -->
```

→ 不是我点不动，是**平台不让改**。原因：推广位属性**跟着媒体属性走**。

### 门 2：媒体属性可以点「正式」，但提交被资质校验拦下

媒体编辑页里「正式」是**可点**的（测试的反而禁用）。点完 `正式[*]` 提交 →
页面展开「媒体资质」区，冒出一串必填：

- 应用名称（**必须和软著中的名称保持一致**）
- 应用商店：TapTap → 选择 TapTap 上架的游戏/应用
- **程序包名**
- **SHA1 值**（只会在 SHA1 填写正确时返回广告）
- **软件著作权证书扫描件**
- 授权书 / 关联证明

→ 当前媒体是「**应用类型=应用 / 系统=Android**」，要的是 APK 的包名和 SHA1。
**我们是 H5 小游戏，根本没有包名和 SHA1**，这条路走不通。

### 门 3：改走「小游戏」就通了大半——但卡在"游戏还没上架 TapTap"

新建媒体 → 应用类型选「**小游戏**」后，表单自己变了：

- 系统自动变成 **「Tap 小游戏」**（不再要 Android/iOS）
- **包名、SHA1、软著证书全部消失**（不再需要）
- 媒体资质只剩一项：**「选择 TapTap 上架的游戏/应用」**

点开这个下拉，里面只有两条：

```
到底谁在演   933387  测试
第七位女嘉宾 921070  测试
```

**没有「解压水消除」。**

→ 结论：**游戏还没有在 TapTap 上架**，所以选不到它，正式媒体就建不出来。

## 三、完整解锁链路（哪一步归谁）

| # | 步骤 | 谁做 | 状态 |
|---|---|---|---|
| 1 | 资质认证（个人主体） | 你 | ✅ 已认证 |
| 2 | **游戏在 TapTap 上架过审** | 你（developer.taptap.cn 提审，要软著/包名等上架材料） | ⛔ **当前唯一硬门槛** |
| 3 | 新建媒体：应用类型=小游戏 + 媒体属性=正式 + 选到第 2 步上架的那个游戏 | 我（CDP 自动化） | 等 2 |
| 4 | 在新媒体下**新建两条推广位**（激励视频 / 插屏），属性随媒体=正式 | 我 | 等 3 |
| 5 | 拿到正式 adUnitId → 回填 `CFG.adUnit`，并把 `CFG.adUnitIsTest` 改成 `false` | 我 | 等 4 |
| 6 | 游戏跑在 **TapTap 容器内**（`window.tap` 由容器注入）才拉得到真实广告 | 上架后自动成立 | 等 2 |

> **第 6 步是另一件事，别和第 2~5 步混在一起**：
> 现在部署在 `https://water-sort-relax.app.workbuddy.host/` 的是**普通 H5 网页**，
> 不在 TapTap 容器里 → `window.tap` 永远不存在 → `AdService` 必定降级成 `test`，
> **就算广告位全是正式位，这个网页版也一毛钱广告收入都不会有**。
> 真收益必须等游戏上架 TapTap 之后。

## 四、代码侧已经准备好的（拿到正式 ID 后一步切换）

`outputs/解压水消除.html`：

```js
adUnit:{rewarded:'1067564',interstitial:'1067565'},  // ← 测试位，拿到正式 ID 后换掉
adUnitIsTest:true,                                    // ← 同时把这行改成 false
```

配套：`AdService.adUnitSrc`（`test-unit` / `formal-unit`）会随 `ad_request`、`ad_show`
两条埋点上报。因为测试位挂上线时**游戏照常玩、不报任何错**，只有埋点里才看得出收益是 0
—— 这个字段就是为了让"拉不到广告"和"拉的是测试位所以不计费"能一眼分开。

> 改 `adUnitIsTest` **不会**改变任何降级逻辑：拉不拉得到广告永远由后台属性决定，
> 代码改不出钱来。它只负责把"现在挂的是测试位"变成看得见的事实。
