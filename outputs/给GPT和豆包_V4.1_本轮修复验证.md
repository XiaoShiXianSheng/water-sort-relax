## 二、这轮改了什么（上一版之后）

### 1. 卡住 / 死局的体验，改成两档

上一版卡住时只给一行文字提示，告诉玩家"点撤销"，但撤销按钮在屏幕底部的另一个地方——**文案指的位置和能点的位置是分离的**。现在：

- **还能救的时候**：提示条下方直接出现 1~3 个**真实可点的按钮**（撤销一瓶 / 随心互换 / 魔法清除 / 解锁台面 / 重开本关），按当前可用性动态生成，用不了的是灰色。这一档的撤销**免费**。
- **真死局**：弹出失败面板，**1.5 秒后**才淡入一个「↩ 撤销一瓶」按钮（0.35 秒过渡）。这 1.5 秒是刻意留的情绪缓冲——刚判死的瞬间把按钮怼脸上等于逼人立刻做决定。
- 撤销次数用光时，这个按钮变成「▶ 看广告 +1 撤销」。**把本来会流失的玩家转成一次广告曝光**，比原来"直接退出、零曝光"严格更优。
- 关键校验：点了撤销之后会**先试算**，如果退回去局面还是走不动，就原样还原、**不扣次数**、只提示去用「重新开始」。不允许出现"花掉最后一次撤销，结果还是死在那儿"。

### 2. 内部代码评审挖出并修掉的 8 个问题

这些不是玩家反馈，是**把 15 万字节的源码逐条读出来**找的，每一条都有代码证据：

| | 问题 | 玩家实际感受到什么 |
|---|---|---|
| B1 | 万能指道具：先扣道具次数，再调 `startPlace()`，而后者在台面满时直接 return | 台面满时**道具白扣一次**，什么也没发生 |
| B2 | 撤销的步数账算错了：快照里压根没存 `moves` 字段，所以撤销恢复不了步数 | 用一次撤销，步数只增不减，反而更难拿三星 |
| B3 | 广告会话上限**永不重置**（`resetSession` 只有定义、零调用），且触顶时三条 toast 互相覆盖 | 提示"下局再来"，但根本不存在下一局 |
| B4 | 点 HUD 的「重开」会把每日挑战**静默降级成普通关**，且绕过了重开记账 | 每日挑战标识消失、成绩不记当天，玩家完全无感 |
| B5 | 道具栏 label 和「▶ 广告补次」画在**同一坐标同一基线**，撤销行是全不透明硬重叠 | 每局必现，两行字糊在一起 |
| B6 | 三星要求"整局零道具" | 掐死了变现：不敢用道具 → 永不耗尽 → 广告补次永远触发不了 |
| B7 | 连点关卡会 toast「再点 N 次进入选关**（测试）**」 | 玩家能看到内部字样 |
| B8 | 新开的口子：失败面板走广告的撤销不受星级封顶约束 | 出现"看完广告还能三星"，与代码里既有原则冲突 |

**B2 有个反直觉的坑，值得你注意**：我一开始想改成"退回瓶子 = 步数 −1"（撤销就该减步数，听起来天经地义）。算完发现**这是错的**——放上去(+1) 和 退回去(−1) 互相抵消后，关底步数会恒等于「瓶子数 + 道具步数」，跟打得好不好完全无关，三星指标当场失效。所以最终只修了"快照补上 moves 字段"，而保留 `startReturn` 的 +1。**如果你有更好的解法，请告诉我。**

### 3. 广告环境切换（TEST / ONLINE）

入口藏在「连点左上角关卡 N 五次」的隐藏测试面板里，**故意不给可见按钮**——应用内带调试开关是常见的上传拒审点。切了之后会把当前档位显示出来；如果点了 ONLINE 但被自动降级（没检测到 TapTap SDK / 没填 adUnitId），会**直接显示降级原因**，避免误以为真实广告已接通。

10 条上线硬条件里有一条是 **「线上字节必须等于本地」**（带 `?t=` 破 CDN 缓存），这条曾经真的抓到过事故：线上一直停在旧版本。

## 四、已知没改的地方，请你们评判（这是我最想要的部分）

我不想只听好话。下面几条是我**主动保留**的取舍，每一条我都想要反对意见：

1. **撤销每关只有 5 次，而且"把瓶子放回货架"也消耗它。**
   评审认为放回瓶子应该和放上去对称、属于基本操作，不该消耗稀缺资源。我**没采纳**，因为撤销次数是"看广告补次"的变现锚点，放开就没人看广告了。代价是玩家每关只有 5 次反悔机会，跟"解压"这个定位有点拧。**这个取舍值不值？有没有第三条路？**

2. **五个浮层在抢屏幕上同一条横带（y≈500~660）**：toast、`hint`（卡住提示）、`warn`（醒目横幅）、模式提示、新手气泡。它们的显示判定互不相斥，任意两个可以同屏。我把它推迟到 v1.1 了，理由是"这是重构，上架前不划算"。**这个判断对不对？会不会成为留存杀手？**

3. **广告还没真正接通**：`adUnitId` 是空的，现在跑的是模拟看完。按计划必须先上传拿 game ID、再开通广告位拿 adUnitId、回填后才能提审。**在还没接通广告的情况下先验证游戏本体，这个顺序合理吗？**

4. **TapTap 还没上传**。卡在一个 MCP 连接器上，可能改用手动上传。**H5 小游戏这种形态，在上架环节有没有我没想到的大坑？**
