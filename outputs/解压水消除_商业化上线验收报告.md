## 7. Online Mode 状态

> 调研结论：TapTap 官方变现现为 **Dirichlet（即 TapADN）**，旧"TapTap 广告 API"已被取代。
> 单 HTML 裸跑在手机浏览器里**无法**直接接 TapTap 广告；必须打包成 **TapTap 小游戏**（在 TapTap App 内运行）后，由小游戏运行时提供广告 JS bridge。

| 项 | 状态 |
|---|---|
| Online Mode 骨架（TapTapAdProvider） | ✅ 已搭骨架：运行时检测 `window.tt` / TapSDK bridge，不存在则 onFailure + 埋点 ad_load_fail(reason:'no_taptap_runtime') |
| 是否申请 Dirichlet(TapADN) 媒体账号 | ❌ 未申请（需开发者操作） |
| 是否创建"小游戏"媒体 + 激励视频/插屏推广位（adUnitId） | ❌ 未创建 |
| 测试广告位 / 正式广告位 | ❌ 待创建 |
| 真实 adUnitId 是否已填入 | ❌ 未填（TapTapAdProvider.init({}) 占位，TODO 注释标注需填入） |
| 真机真实广告是否跑通 | 待用户真机复测（需先打包为 TapTap 小游戏） |

Online Mode 结论：**骨架已就绪，等待 Dirichlet 账号与 adUnitId**。
> 在拿到 Dirichlet 账号与 adUnitId 之前，Online Mode 只能是空骨架。代码已锁死：无 bridge 时绝不白送奖励（自动化用例验证 TapTapAdProvider 在无运行时时调用 onFailure）。
